## 学生认证后如何使用 GitHub Copilot Pro / How to Use GitHub Copilot Pro After Student Verification

### 问题 / Problem

已完成 GitHub 学生认证，但无法使用 Copilot Pro？以下是常见原因和解决步骤。

> Already completed GitHub student verification but cannot use Copilot Pro? Here are the common causes and resolution steps.

---

### 常见原因及解决方法 / Common Causes & Solutions

#### 1. 确认 GitHub Education 认证状态 / Confirm GitHub Education Verification Status

- 访问 [https://education.github.com](https://education.github.com) 并登录你的 GitHub 账号。
- 确认你的申请状态为 **"Approved"（已批准）**，而不是"Pending"（审核中）或"Rejected"（已拒绝）。
- 如果状态仍为 "Pending"，请耐心等待审核（通常需要几天）。

> - Visit [https://education.github.com](https://education.github.com) and sign in to your GitHub account.
> - Make sure your application status is **"Approved"**, not "Pending" or "Rejected".
> - If still "Pending", please wait for the review (usually takes a few days).

#### 2. 确认 GitHub Student Developer Pack 已激活 / Confirm Student Developer Pack is Active

- 访问 [https://education.github.com/pack](https://education.github.com/pack) 查看 Student Developer Pack 是否已激活。
- Copilot Pro 的免费学生权益通过 Student Developer Pack 提供。

> - Visit [https://education.github.com/pack](https://education.github.com/pack) to check if the Student Developer Pack is active.
> - Free Copilot Pro access for students is provided through the Student Developer Pack.

#### 3. 在 GitHub 设置中启用 Copilot / Enable Copilot in GitHub Settings

1. 登录 GitHub，点击右上角头像 → **Settings（设置）**。
2. 在左侧菜单找到 **Copilot** 选项。
3. 确认 Copilot 已启用，如果看到"Start free trial"或付费选项，说明学生权益未正确绑定，请重新检查步骤 1 和 2。

> 1. Sign in to GitHub, click your avatar (top right) → **Settings**.
> 2. Find **Copilot** in the left-side menu.
> 3. Confirm Copilot is enabled. If you see "Start free trial" or a paid option, your student benefit is not linked correctly — revisit steps 1 and 2.

#### 4. 使用相同的 GitHub 账号 / Use the Same GitHub Account

- 确保你用于学生认证和使用 Copilot 的是**同一个 GitHub 账号**。

> - Make sure you're using the **same GitHub account** for both student verification and Copilot.

#### 5. 等待权益同步 / Wait for Benefit Synchronization

- 学生认证通过后，权益有时需要最多 **24 小时**才能同步到账号。请稍等后再试。

> - After student verification is approved, benefits may take up to **24 hours** to sync. Please wait and try again later.

#### 6. 联系 GitHub Support / Contact GitHub Support

如果以上步骤均无法解决问题，请访问 [https://support.github.com](https://support.github.com) 提交支持请求，说明：
- 你已完成学生认证（提供截图或认证邮件）
- 你的 GitHub 用户名
- 无法访问 Copilot Pro 的具体表现

> If none of the above steps resolve the issue, visit [https://support.github.com](https://support.github.com) and submit a support request, including:
> - Proof of your student verification (screenshot or approval email)
> - Your GitHub username
> - A description of the issue with accessing Copilot Pro
